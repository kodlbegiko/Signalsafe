# SignalSafe v0.2 核心 QA

## 首頁

- [ ] 主要 CTA 是「開始 90 秒快練」
- [ ] 急救模式為次要入口
- [ ] 不顯示前台 AI 判定或「完全安全」

## 90 秒快練

- [ ] 每次 3 題
- [ ] 至少 1 題明顯風險
- [ ] 至少 1 題資訊不足或目前較可信
- [ ] 每題只選安全行動＋一個訊號
- [ ] 解析提供官方查證路徑

## 完整能力測驗

- [ ] 前測 8 題不立即顯示答案
- [ ] 訓練 8 題逐題解析
- [ ] 後測 8 題使用不同情境
- [ ] 每題記錄行動、三分類、證據與自信
- [ ] 可暫停並在同一裝置繼續

## 急救模式

- [ ] 不要求貼上真實訊息或截圖
- [ ] 不要求帳密、OTP 或金融資料
- [ ] 只提供停止與獨立查證步驟

## 儀表板

- [ ] 快練不顯示虛假的三分類分數
- [ ] 完整測驗顯示 macro recall 與較可信誤判率
- [ ] 全部選高風險無法得到高校準分

## 資料

- [ ] JSON 匯出
- [ ] CSV 匯出
- [ ] JSON 匯入
- [ ] 清除資料
- [ ] 不需登入且不收姓名、學校、電話或 Email

- [ ] 桌面版核心流程可操作
