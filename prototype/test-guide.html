SignalSafe Pilot 原型測試說明

本頁把目前 Pilot 的測試情境、四項任務、測試場域、招募條件與主持人提示規則固定下來。Pilot 建議先收 5–8 名受測者，驗證流程、題目理解與資料匯出可靠性；不把這一輪直接宣稱為正式教育成效研究。

A. 設定測試情境

主持人以高中生日常數位使用情境帶入，不先把受測者推進「每一題都一定是詐騙」的警戒模式。

主持人口語稿：
想像你平常會使用 LINE、Instagram、遊戲、購物平台和其他網路服務，也可能收到活動通知、帳號提醒、付款要求或陌生訊息。今天我們想了解高中生面對這些數位訊息時，會如何判斷情況並選擇下一步。請依照你當下最真實的直覺操作，不需要猜研究者想要的答案；這不是學校考試。

B. 設定測試任務

  1. 從 SignalSafe 首頁找到適合參與正式研究測試的入口，並開始測試。
  2. 閱讀研究參與說明，依照自己的理解完成必要確認並進入正式測試。
  3. 依照當下真實判斷，完成系統提供的 Pre-test、Training 與 Post-test 情境流程。
  4. 完成後查看結果頁，指出自己最需要加強的地方，並向主持人說明這套系統是否有幫助、哪裡需要修改。

C. 設定測試場域

場域學校圖書館、自習空間或等價的安靜校內空間
形式一次一名受測者、個別進行
設備統一使用 iPad Air 與 Safari；橫向或直向由受測者自然選擇
網路使用穩定 Wi-Fi，開始前先確認正式網站可正常載入
主持人位置坐在側後方觀察，不主動提示答案或操作路徑
干擾控制避免同學在旁提供答案；非必要通知與其他 App 先關閉

D. 招募受測者需符合的關鍵屬性

  1. 16–18 歲、高中階段學生。
  2. 日常有使用智慧型手機，以及 LINE、Instagram、遊戲、購物平台或其他數位服務的經驗。
  3. 能自行閱讀繁體中文並完成一般網頁操作。
  4. Pilot 可曾使用 SignalSafe 一般模式，但未曾完成同版本的正式 Research Mode，以降低重複作答造成的學習效應。
正式成效研究：未來若進入正式 effectiveness study，應再採更嚴格的既往暴露排除規則，不與本次 Pilot 樣本定義混用。

主持人提示規則

  1. Level 0：不提示，讓受測者自行完成。
  2. Level 1：只說「請再看看畫面上還有哪些選項」，不指出位置。
  3. Level 2：只提示功能所在區域，不告訴受測者應選哪一個答案。
  4. Level 3：為避免流程完全中斷，直接說明操作方式；必須記錄使用了 Level 3。

每一項任務記錄受測者最高需要到哪一級提示。這樣後續可以比較「能否獨立完成」，而不是只記最後有沒有做完。

Pilot 建議執行順序

報到 → 外部研究說明／必要同意程序 → 匿名 Participant ID → 從首頁自行找到 Research Mode → 網站研究參與說明與確認 → Pre 8 → Training 8 → Post 8 → 匯出研究 JSON → 3–5 分鐘簡短訪談。
