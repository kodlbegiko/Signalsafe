## 使用與限制

- 所有圖片使用現行凍結的 **16–18 歲高中階段學生**定位。
- SVG 是可版本控制的呈現資產，不取代 Markdown 內容、來源卡及匿名原始紀錄。
- 探索訪談不能代表所有高中生。
- 可用性測試不能直接證明教育成效或降低真實受騙率。
- 作業四結果模板只有在完成相應測試後，才能以真實匿名彙總資料取代空格。
