## 使用與限制

- 圖片使用現行凍結的 **16–18 歲高中階段學生**定位。
- 圖片為可版本控制的 SVG 視覺稿，不取代 Markdown 原始內容與證據附件。
- 探索訪談與可用性測試不得被誤寫為已證明教育成效。
- 作業四目前呈現的是正式測試準備；需完成兩輪 8–12 人測試後，才能加入真實結果圖。
