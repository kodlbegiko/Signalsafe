# SignalSafe 資料處理政策

## 公開 Repository 可以收錄

- 匿名化研究摘要
- 不含身分資料的彙總數據
- 題庫與評分規則
- 研究方法、同意書空白範本
- 會議整理稿
- 來源與證據紀錄

## 公開 Repository 不得收錄

- 真實姓名與匿名編號對照
- 電話、Email、學校、班級
- 未成年人聯絡資訊
- 原始會議音檔
- 可辨識聲音、照片或影片
- 未經再次確認的逐字稿
- 真實可點擊詐騙連結

## 受測者編號

使用 `U001`、`U002` 等匿名編號。姓名對照表必須保存在 Repository 之外，並限制存取。

## 延遲後測聯絡

若需第 7 天後測，聯絡資訊應另存於獨立檔案，不能與作答 CSV 使用相同主鍵直接連結。建議使用一次性聯絡代碼。

## 公開資料最小化

只公開回答研究問題所需的最小資料。小樣本資料若可能由時間、背景或語句反推身分，應只公開彙總結果。

## 目前明確排除

- 第二、三次會議原始 MP3
- 受訪者姓名—匿名編號對照
- 未成年人聯絡資料
- 尚未與原始匯出檔核對的完整聊天轉錄 JSON
