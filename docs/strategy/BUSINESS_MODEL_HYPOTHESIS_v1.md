# SignalSafe 商業模式假設 v1

## 建議方向：混合式 B2C / B2B2C / B2G-CSR

### 學生端
核心反詐決策訓練維持低門檻或免費，優先累積真實使用、可用性與研究證據。現階段不假設學生會直接訂閱付費。

### 學校端 B2B2C
下一階段驗證學校是否願意為以下價值付費或投入資源：
- 課程導入與教師教案／主持資源。
- 匿名班級層級能力洞察，不提供個人敏感資料。
- 可版本化的新型詐騙情境與定期更新。

### 政府／企業合作
探索政府反詐、金融機構、電信業者或其他企業 CSR 計畫贊助校園導入的可能性。

## 商業驗證順序
1. 完成 5–8 人 Pilot，先證明流程可用與資料可收。
2. 訪談教師、學校行政或教育單位，確認導入痛點與採購流程。
3. 訪談可能的 CSR / 政府合作方，確認合作價值與必要證據。
4. 才進入定價、成本、單位經濟與付費實驗。

## 不可提前宣稱
在沒有真實採購、合作或 willingness-to-pay 證據前，不可宣稱：
- 學校願意付費。
- 政府或企業已承諾合作。
- 某個價格已被市場接受。
- SignalSafe 已具可規模化商業模式。
