# SignalSafe 市場可行性評估作業 v1

版本：`signalsafe-market-feasibility-2026-08-13-v1`

> 本作業把「目前方案」與「升級後方案」分開。商業模式、採購者與合作方式目前仍屬待驗證假設，不宣稱已取得採購承諾或教育成效證明。

## 永續議題重要性

### 目前方案
- 聚焦 16–18 歲學生的數位反詐決策訓練，而不是只做單次真假判定。
- 核心價值是降低財務、帳號與個資風險，提升可持續的數位社會韌性。
- 已有目標族群定義、情境題庫與 Pilot 研究流程作為問題驗證基礎。

### 升級後方案
- 將反詐能力定位為可持續的數位公民與安全決策能力。
- 建立校園常見情境與新型詐騙手法的持續更新機制。
- 以 Pilot 與後續正式研究證據檢驗是否真的改善「安全下一步」。

## 目標對象真實需求

### 目前方案
- 主要對象為 16–18 歲高中階段學生，日常高度接觸手機、社群、遊戲、購物與數位服務。
- 核心需求假設不是「再多知道一些詐騙知識」，而是能在壓力情境中練習先停下、找重點、去查證。
- 已建立 Pre / Training / Post 與 5–8 人 Pilot 流程。

### 升級後方案
- 先用 5–8 人 Pilot 驗證介面、題目理解、情境真實感與資料流程。
- 依 construct 弱點與錯誤型態決定下一輪補強情境。
- 正式研究前凍結版本、招募條件與主持流程，維持資料可比較性。

## 科技適切性

### 目前方案
- 使用瀏覽器 / PWA 降低安裝門檻，可在手機、平板與桌面使用。
- Research Mode 支援匿名 Participant ID、Pre / Training / Post、暫停恢復與 JSON 匯出。
- Quick bank 與正式研究題庫分離，避免污染前後測。

### 升級後方案
- 持續維持跨裝置、低安裝摩擦與同站研究入口。
- 建立題庫與情境內容的版本治理、人工語意審查與可追溯更新流程。
- 未來再驗證學校端匿名班級洞察與教師資源需求；在需求成立前不增加 PII 或複雜後台。

## 商業可行性

### 目前方案
- 尚未驗證學生或家長直接付費意願，也沒有足夠證據支持特定定價。
- 潛在採購者可能包括學校、教育單位、政府，以及金融、電信或其他企業 CSR 夥伴。
- 因此現階段商業模式應視為待驗證假設。

### 升級後方案
- 採混合模式：學生核心訓練維持低門檻或免費。
- B2B2C：驗證學校對課程導入、教師資源與匿名群體能力洞察的授權需求。
- B2G / CSR：探索政府、金融、電信或企業社會責任計畫支援校園導入。
- 先用 Pilot、採購者訪談與合作意願驗證需求，再決定定價、成本與單位經濟。

## 可持續發展性

### 目前方案
- 題庫、Study、Consent 與 Pilot protocol 已版本化，具研究可追溯性。
- 匿名作答資料可以辨識共同弱點與需要補強的 construct。
- 長期內容更新、專家審查頻率與維運責任尚未制度化。

### 升級後方案
- 建立 `Threat → Training → Measurement → Update` 持續循環。
- 依新型詐騙事件、校園回饋與研究結果定期更新情境。
- 每次題庫改版保留版本、語意審查、測試證據與舊資料邊界。
- 建立合作學校、教師與反詐專家的長期回饋網路。

## 團隊資源

### 目前方案
- 現有能力涵蓋產品原型、Web 前端、研究流程、版本控制、CI 與部署。
- 已有 Pilot 主持人流程、招募條件、Research Mode 與資料匯出基礎。
- 缺口包含反詐領域專家、教學設計、心理測量 / 研究方法、大規模校園導入與商業合作資源。

### 升級後方案
- 核心團隊持續負責產品、研究工程與資料品質。
- 邀請反詐 / 金融專家參與情境與答案人工審查。
- 與教師及學校夥伴合作做教學整合、Pilot 招募與場域驗證。
- 引入研究方法顧問協助測量設計，並尋找企業 / 政府夥伴支援擴大導入。
