# SignalSafe 可持續發展與團隊資源計畫 v1

## 持續發展循環

`Threat → Training → Measurement → Update`

1. **Threat**：持續收集新型詐騙手法、校園常見數位情境與合作夥伴回饋。
2. **Training**：把風險轉成可練習的情境，不直接把真實詐騙訊息原樣搬入產品。
3. **Measurement**：用匿名 construct、safe-action、signal、confidence 與前後測資料找出共同弱點。
4. **Update**：依證據更新情境與教學內容，並為每次題庫變更保留版本、語意審查與 QA 證據。

## 現有團隊能力
- Web / PWA 原型與前端實作。
- Research Mode、匿名研究資料、版本化研究流程。
- GitHub、CI、自動測試與 Vercel 部署流程。
- Pilot 主持人流程、招募條件與資料匯出。

## 需要補強的資源
- 反詐／金融領域專家：審查情境與安全行動。
- 教師／教學設計夥伴：確認課堂導入與學生理解。
- 心理測量／研究方法顧問：確認 construct、量表與分析方法。
- 學校合作管道：進行 Pilot、正式研究與後續導入。
- 商業／政府合作資源：驗證採購、CSR 與擴大導入模式。

## 角色分工原則
核心團隊保留產品與研究工程所有權；專家夥伴不只是背書，而應在題目審查、研究方法、教學導入或擴散路徑上產生可驗證貢獻。

## 成長門檻
在以下證據不足前，不把「可持續成長」宣稱成已成立：
- Pilot 流程可靠。
- 人工題目審查完成。
- 至少有學校／教師導入需求證據。
- 有明確內容更新責任與審查節奏。
- 有可行的維運成本與合作資源來源。
