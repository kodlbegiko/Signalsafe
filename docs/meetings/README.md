- 如果要快速看四次會議如何演進，先看 `MEETING_RECORDS_DETAILED_MASTER.md`。

## 使用原則

- 會議紀錄中的「事實／導師回饋／團隊當時狀態」與「後續推導」分開理解。
- 第二、三、四次目前不是完整逐字稿，因此不應把重建內容當成逐字引述。
- 原始錄音可能包含參與者聲音與個人資訊，不上傳公開 repository。
- 若後續取得第二、三、四次完整逐字稿，應以逐字稿重新校對並更新本文。
