## 1｜目標對象人物誌

### 化名

小宇

### 基本資料

| 欄位 | 內容 |
|---|---|
| 年齡 | 16–18 歲 |
| 身分 | 高中階段學生 |
| 常用平台 | Instagram、Threads、LINE、Facebook、遊戲與影音平台 |
| 數位情境 | 社群私訊、遊戲福利、票券、二手交易、打工及活動報名 |
| 防詐基礎 | 知道不要隨意提供個資或點擊可疑連結，但缺乏穩定判斷流程 |

### 典型行為

- 收到可疑訊息時通常不會立刻回覆
- 會比對官方網站、搜尋資料或詢問家人與可信任朋友
- 可能忽略、封鎖或停止操作明顯可疑帳號
- 對限時、中獎、帳號異常及金錢要求等字詞敏感
- 容易依賴單一關鍵字，或把正常／資訊不足訊息一併判為詐騙

### 核心需求

1. 快速判斷訊息是否出現明顯風險
2. 理解真正重要的可疑原因
3. 知道下一步如何查證、封鎖、檢舉或求助
4. 在 1–3 分鐘內完成短訓練
5. 使用情境式、互動式且不幼兒化的學習方式

### 主要痛點

- 判斷標準不完整
- 過度誤判正常資訊
- 查證流程分散
- 不熟悉檢舉與通報方式
- 傳統宣導缺乏參與感

### 使用目標

> 收到社群、遊戲、票券、交易或帳號通知時，能先停止高風險操作，找出最重要訊號，並改走官方且獨立的查證管道。

## 2｜親和圖

### 詐騙接觸情境

- 假遊戲福利、假中獎通知
- 陌生社群內容、熟人帳號投票
- 可疑連結、要求登入或提供個資
- 票券、二手交易、打工與活動邀請

### 判斷困難

- 依賴單一關鍵字
- 難以區分有明顯風險、資訊不足與目前較可信
- 缺少固定判斷順序
- 知道要查證，但不知道先查哪裡
- 可能把正常訊息誤判成詐騙

### 現有安全行為

- 不立即回覆、不提供個資
- 不點擊可疑連結
- 比對官方網站
- 詢問父母、老師或朋友
- 封鎖可疑帳號

### 期待功能

- 真實案例與後果
- 遊戲化情境與可疑點提示
- 語音或短影音
- 查證、封鎖、檢舉與通報教學
- 可轉傳給家人的簡短提醒

### 使用限制

- 五分鐘對部分使用者過長
- 操作不能複雜
- 文字不能像長篇宣導教材
- 日常訓練宜控制在 1–3 分鐘

## 3｜需求洞察

三位探索訪談顯示，學生不是完全沒有防詐警覺。他們通常知道不應提供個資，也會搜尋官方資料或詢問家人。

真正的問題是：

> **學生缺少一套能在資訊不完整、時間壓力及熟人情境下，快速辨識高風險操作並採取安全下一步的固定流程。**

```mermaid
flowchart LR
  A[看到訊息] --> B[判斷是否要求高風險操作]
  B --> C[找出最重要風險訊號]
  C --> D[停止點擊／登入／付款／提供資料]
  D --> E[回到官方 App、官網或原聯絡方式]
  E --> F[封鎖／檢舉／165／向可信任者求助]
```

## 4｜設計觀點 POV

> **一位高頻使用社群、通訊、遊戲與數位服務，具基本防詐警覺的 16–18 歲高中生，需要一套短時間、情境化且能清楚解釋風險的訓練工具，因為他雖然知道不要亂點連結或提供個資，卻仍缺少穩定的判斷流程，也不清楚如何查證、封鎖、檢舉或求助。**

## 5｜How Might We

> **我們如何透過約 60–90 秒的情境化訓練，幫助 16–18 歲高中生在社群、遊戲、交易與活動訊息中，辨識最重要訊號、停止高風險操作，並改走官方查證、封鎖、檢舉或求助？**

## 6｜產品設計回應

| 使用者需求 | SignalSafe 設計回應 |
|---|---|
| 快速完成 | 90 秒快練，每次少量情境 |
| 不只判真假 | 先選最安全行動，再找最重要訊號 |
| 理解原因 | 拆解話術、來源、行為及金流風險 |
| 避免全部判高風險 | 評分納入較可信誤判率與三分類校準 |
| 知道下一步 | 官方查證、封鎖、檢舉、165 與求助流程 |
| 提升參與感 | 社群、遊戲、票券、交易與校園情境 |
| 支援研究 | 完整模式保留三分類、證據、自信與計時 |
