## 使用原則

1. 圖片是呈現資產，Markdown 與證據附件才是可追溯內容。
2. 三位既有受訪者屬探索性樣本，不代表全臺高中生。
3. 使用者姓名、聯絡資料、原始聲音與可識別影像不得進入公開 Repository。
4. 結果圖片模板不得填入預測數據或被誤寫為已完成測試。
5. 功能可運作、可用性成立與教育成效成立是三個不同層級。
6. 官方教材原始 PDF 未確認公開再散布授權，因此只保存來源索引、雜湊與內容對照。
