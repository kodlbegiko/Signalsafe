## 3-4：提出一個有未來潛力的解決方案

### 截圖狀態

- 「初賽提案」區塊空白
- 「複賽－未來潛力的解決方案」區塊空白

### 現行可用的方案描述

> **SignalSafe 是一套面向 16–18 歲高中階段學生的防詐決策訓練系統。它透過 90 秒情境快練、個人盲點、變形題及延遲複習，訓練學生在社群、遊戲、票券、交易與打工情境中停止高風險操作，並改走官方且獨立的查證管道。**

### 初賽到複賽的升級

| 初期方向 | 複賽收斂方向 |
|---|---|
| 泛用反詐測驗或 AI 判定構想 | 防詐決策訓練系統 |
| 可能替使用者判真假 | 訓練使用者做出安全下一步 |
| 每題流程偏重 | 日常快練只保留行動＋關鍵訊號 |
| 單次答題 | 盲點診斷、變形題與第 7 天複習 |
| 功能完成為主 | 可用性與教育成效分開驗證 |

6. 系統引導回到官方 App 或原聯絡方式查證
7. 使用者停止高風險操作，並封鎖、檢舉或求助
8. 後續以不同表面情境測試是否能遷移同一原理

- 目標對象真實需求

- 商業可行性
- 可持續發展性
- 團隊資源

### 截圖狀態

- 「未來潛力的解決方案」與「升級後方案」兩列仍未填寫
- 六個評估欄位仍為空白

### 建議填寫方向

| 面向 | SignalSafe 初步判斷 | 尚缺證據 |
|---|---|---|
| 議題重要性 | 青少年高頻接觸數位訊息，防詐為持續性公共議題 | 需維持可追溯官方資料 |
| 真實需求 | 三位探索訪談顯示有短訓練、具體行動及查證需求 | 需 16–18 歲正式樣本 |
| 科技適切性 | PWA、本機資料、可離線與可更新題庫可行 | 需實際裝置與校園網路測試 |
| 商業／導入可行性 | 可由學校、課程、社團或公共單位導入 | 需教師、學校及合作單位訪談 |
| 可持續發展 | 題庫可隨新情境更新，資料可支持弱項診斷 | 需建立內容維護與審核流程 |
| 團隊資源 | 已有原型、研究規格與競賽文件 | 尚缺正式原始碼、測試樣本與題庫審核 |
