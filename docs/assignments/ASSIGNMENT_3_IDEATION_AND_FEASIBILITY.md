## 3-2｜國內外相關案例分析

完整來源卡見：[作業三案例來源卡](../evidence/ASSIGNMENT_3_CASE_SOURCE_CARDS.md)。

| 案例 | 主要用途 | 優點 | 邊界 | SignalSafe 可學習之處 |
|---|---|---|---|---|
| 165 全民防騙網 | 官方查證、報案、檢舉及涉詐公告 | 權威、正式處理入口、資訊持續更新 | 非個人化反覆訓練 | 結果頁必須提供官方查證、檢舉與求助下一步 |
| Whoscall | 來電、電話、連結、截圖與訊息風險查詢 | 快速、貼近日常通訊、輸入型態多 | 主要是辨識與防護，不以能力遷移為核心 | 清楚顯示風險理由；與訓練工具互補而非互相取代 |
| Google Messages | 垃圾／詐騙訊息偵測、封鎖及回報 | 安全功能整合在通訊流程 | 場景限於特定產品，自動偵測不能涵蓋所有新情境 | 安全行動應簡短、流程內建；仍需訓練資訊不足時的決策 |

### 案例分析結論

> 成熟工具已能提供官方查證、辨識、過濾、封鎖與回報。SignalSafe 的缺口定位不是「比它們更準」，而是反覆情境練習、個人盲點、變形題遷移與延遲保留測量。

## 3-4｜有未來潛力的解決方案

### 收斂方案

> **SignalSafe 是一套面向 16–18 歲高中階段學生的防詐決策訓練系統。它透過 90 秒情境快練、個人盲點、變形題及延遲複習，訓練學生在社群、遊戲、票券、交易與打工情境中停止高風險操作，並改走官方且獨立的查證管道。**

### 初賽到複賽的升級

| 初期方向 | 複賽收斂方向 |
|---|---|
| 泛用反詐測驗或 AI 判定構想 | 防詐決策訓練系統 |
| 替使用者猜真假 | 訓練使用者做出安全下一步 |
| 每題流程偏重 | 日常只保留行動＋一個訊號 |
| 單次答題 | 盲點、變形題與延遲複習 |
| 功能完成為主 | 可用性與教育成效分開驗證 |
| 多族群同時服務 | 第一階段固定 16–18 歲高中階段學生 |

### 六構面可行性

| 構面 | 升級後方案判斷 | 現有證據 | 尚缺驗證 |
|---|---|---|---|
| 永續議題重要性 | 數位詐騙與安全決策是持續性社會議題 | 官方防詐公告、競賽永續社會方向 | 不宣稱已降低受騙率 |
| 目標對象真實需求 | 有基本警覺但缺固定流程與具體下一步 | 3 位探索性訪談 | 8–12 位正式目標族群可用性測試 |
| 科技適切性 | PWA、本機資料、短情境與更新題庫可行 | 已有原型與技術規格 | 新版原型與真實裝置驗證 |
| 商業／導入可行性 | 學生免費，由學校、教師或公共單位導入 | 校園可接觸、教材與競賽場域 | 教師、校方與合作單位訪談 |
| 可持續發展性 | 題庫可更新，盲點資料可支持後續複習 | 題庫結構、版本及人工審核設計 | 長期內容維護、審核與成效資料 |
| 團隊資源 | 已有產品規格、作業、測試包與原型歷史版本 | GitHub 單一事實來源 | 新版程式碼、測試執行與專家審題 |

### 為什麼選這個方案

- 直接回應訪談中的「時間短、要知道原因與下一步」。
- 與 165、Whoscall、Google Messages 形成互補，而非重複製作另一個辨識器。
- 能以任務完成率、判斷校準與安全行動測量，不只依賴主觀喜好。
- 可先用低風險、本機化原型驗證，再決定是否擴充 AI 或校園後台。

## 3-5｜故事版

1. 高中生收到朋友帳號傳來的限時投票訊息。
2. 訊息要求從外部連結登入帳號。
3. 使用者知道要小心，但不確定熟人訊息是否可信。
4. 他進入 SignalSafe 的 90 秒快練。
5. 系統先要求選擇最安全行動，他選擇停止登入並回原聯絡方式查證。
6. 他找出「熟人帳號＋限時壓力＋外部登入」中的關鍵訊號。
7. 系統提供官方查證、封鎖、檢舉與求助步驟。
8. 後續以票券或打工變形題測試他能否遷移同一安全原理。
