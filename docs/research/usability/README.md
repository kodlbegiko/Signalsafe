## Evidence boundary

目前可對外說明的真人證據是：2026-08-17 exploratory usability observation 的 3 participants、15/15 core task completion、0/15 moderator intervention，以及由此造成的三項產品修改。

目前不可把這些觀察外推成提升防詐能力、降低受騙率、learning effect、unseen-scenario transfer、Day-7 retention、統計顯著改善或正式教育成效。
