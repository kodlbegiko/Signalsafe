# 招募、篩選與參與者同意模板

> 本模板不是法律文件。若在學校或正式機構執行，應以該場域規定為準。

## 1. 可直接傳送的招募訊息

你好，我們正在測試一個給 16–18 歲學生使用的防詐情境訓練網站 SignalSafe。

測試約 15–20 分鐘，內容是操作幾個模擬的社群、遊戲或交易情境，並告訴我們哪些地方看不懂或不好操作。這不是考試，也不會要求提供真實帳號、密碼、OTP、學校或個人訊息。

- 對象：16–18 歲高中階段學生
- 時間：約 15–20 分鐘
- 資料：使用匿名編號，不公開姓名
- 錄製：不錄臉；預設不錄原始聲音
- 退出：過程中可隨時停止，不需要說明理由

未滿 18 歲者會依測試場域要求取得家長、監護人或校方的適當同意。

## 2. 招募前最低必要篩選

1. 是否為 16–18 歲？
2. 是否為高中、技高或符合年齡的五專低年級學生？
3. 是否平常使用智慧型手機與社群／通訊軟體？
4. 是否為 SignalSafe 開發團隊成員？
5. 是否已完整看過正式測試題目？
6. 是否願意參與約 15–20 分鐘的匿名操作測試？
7. 未滿 18 歲者是否可依場域完成適當同意？

## 3. 排除條件

- 不在 16–18 歲範圍
- 為開發團隊成員
- 已完整接觸正式題庫
- 無法完成必要同意程序
- 不願意匿名記錄操作結果

## 4. 配額原則

- 16、17、18 歲盡可能均有涵蓋
- 不全為同一班級或同一朋友圈
- Round 1 與 Round 2 不重複受測者
- 不記錄學校名稱；只記學制類型

## 5. 參與者說明

### 測試名稱

SignalSafe 16–18 歲新版原型可用性測試

### 測試目的

了解網站的文字、按鈕、題目與流程是否清楚。這不是個人防詐能力的正式評量，也不是學校考試。

### 參與內容

1. 操作 90 秒快練。
2. 閱讀風險回饋。
3. 查看個人盲點或學習紀錄。
4. 操作急救模式。
5. 回答簡短使用感受問題。

預計 15–20 分鐘。

### 不會要求的資料

- 真實帳號或密碼
- OTP 或金融資料
- 真實可疑訊息或截圖
- 姓名、學校、班級
- 社群帳號
- 臉部影像

### 紀錄方式

- 使用 `UT001–UT012` 匿名編號
- 預設不錄原始聲音
- 不錄臉
- 只有另行同意時，才錄製不含個資的操作畫面
- 聯絡資料與作答資料分開保存
- 公開 GitHub 只放匿名彙總資料

### 自願與退出

參與完全自願。參與者可在任何時間暫停或退出，不需要說明理由，也不會有任何不利影響。

### 可能風險

部分情境涉及詐騙、帳號遭盜或金錢損失，可能讓人感到不舒服。參與者可跳過題目或停止測試。

## 6. 保存原則

- 聯絡資料：完成必要聯絡後刪除，最晚不超過最後一次聯絡後 30 天
- 匿名測試資料：保存至競賽與研究整理完成後一年，再重新評估是否刪除
- 若學校或場域有更嚴格規定，以其規定為準
