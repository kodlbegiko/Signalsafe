# SignalSafe Exploratory Usability Observation — 2026-08-17

Status: **COMPLETED — exploratory usability only**
Date: **2026-08-17**

## Purpose

這次操作是送件前的 **exploratory usability observation**，目的在確認目標使用者能否理解並完成 SignalSafe 的核心操作路徑，以及觀察介面／導覽是否需要迭代。

它不是 Formal Round 1、不是 scored learning study，也不是用來估計防詐教育成效的實驗。

## Participants

- `n = 3`
- age = `18`（3 位皆為 18 歲）
- target-user range context = `16–18`

本公開紀錄只保留完成 evidence boundary 所需的最小資訊；不在此文件加入姓名、學校、聯絡方式或其他可識別資料。

## Tasks

每位參與者完成同一組 5 個核心任務：

1. 開始快練。
2. 完成 3 題。
3. 查看結果。
4. 找到急救功能。
5. 回到首頁。

總計：`3 participants × 5 tasks = 15 core tasks`。

## Observed results

- Core task completion: **15/15**。
- Moderator intervention: **0/15**。

這些數字描述的是當次操作中的任務完成與主持人介入情況，不是學習分數、前後測改善、transfer score 或防詐成效指標。

## Design changes caused by this observation

1. **Positioning changed to「安全決策訓練」**
   將產品價值更清楚地放在「做對安全下一步」，而不是讓使用者以為 SignalSafe 會替他判斷訊息真假。

2. **Quick Training entry moved forward**
   降低開始練習的導覽成本，讓核心訓練入口更直接。

3. **English UI wording simplified**
   將較不直覺的英文介面詞彙改成更白話的使用者語言。

## Evidence boundary

**This observation supports usability and design iteration only.**

It supports:

- usability;
- task completion;
- navigation / interaction feasibility;
- design iteration。

It does **NOT** establish:

- learning effectiveness;
- scam-prevention effectiveness;
- unseen-scenario transfer;
- Day-7 retention;
- reduction in victimization;
- statistical significance;
- any formal educational-effect claim。

沒有公開或偽造 participant quote、before/after improvement、learning gain 或 statistical claim。
