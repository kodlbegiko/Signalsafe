# 版本凍結、技術檢查與資料治理

## 1. 版本資料

每一輪測試前必須記錄：

- App version
- Question bank version
- Git commit
- 部署網址
- 凍結日期
- Round
- 主持人及觀察員

建議版本：

- Round 1：`v0.2-usability-r1`
- Round 2：`v0.2-usability-r2`

## 2. 流程檢查

- [ ] 首頁主 CTA 是「開始 90 秒快練」
- [ ] 急救模式是次要入口
- [ ] 日常快練只要求最安全行動＋一個最重要訊號
- [ ] 研究模式才包含三分類、證據與自信
- [ ] 沒有 `safe / unsafe` 抽象選項
- [ ] 沒有「完全安全」文字
- [ ] 沒有 AI 最終真假判定

## 3. 資料與隱私

- [ ] 不需登入
- [ ] 不收姓名、學校、班級、電話或 Email
- [ ] 不要求真實訊息或截圖
- [ ] 匿名 ID 可正確保存
- [ ] 匯出包含 App／題庫版本、信心及中斷欄位
- [ ] 清除測試資料功能可用
- [ ] 公開 GitHub 不含聯絡資料

## 4. 評分

- [ ] 全部選高風險不會取得高分
- [ ] 三類情境均有題目
- [ ] 安全行動是具體選項
- [ ] 速度不直接加分

## 5. 裝置與備援

- [ ] 360px 寬度可操作
- [ ] iPhone Safari 已測
- [ ] Android Chrome 已測
- [ ] 桌面瀏覽器已測
- [ ] 關閉通知預覽及私人分頁
- [ ] 測試裝置電量足夠
- [ ] 本地／離線版本可用
- [ ] 示範錄影、紙本表格、備用裝置及充電器已準備
- [ ] 每位受測者前清除上一位本機資料

任何 P0 項目未通過，不得開始正式場次。

## 6. 匿名編號

- `UT001–UT004`：Round 1
- `UT005–UT012`：Round 2
- `DRYRUN-*`：主持與技術演練

不得沿用 U001–U003，避免與前期探索訪談混淆。

## 7. 公開資料可包含

- 匿名編號
- 年齡 16／17／18
- 學制類型，但不記學校名稱
- 測試輪次及版本
- 任務完成狀態、時間及提示次數
- 問卷分數
- 不可識別的匿名原話
- 問題嚴重度及修改結果

## 8. 不得進入公開 Repository

- 姓名與匿名編號對照
- 電話、Email、社群帳號
- 學校與班級
- 簽名或同意書影像
- 原始聲音及臉部影像
- 未裁切且可辨識個人的螢幕錄影
- 真實可疑訊息、帳號、OTP 或金融資訊

## 9. 聯絡資料

若為排程而保存聯絡方式：

- 與作答資料分開
- 不上傳 GitHub
- 只保存最低必要資料
- 最後一次聯絡後 30 天內刪除
- 建立刪除日期與執行者紀錄

## 10. 檔名規則

- `UT001-session.json`
- `UT001-observation.csv`
- `UT001-questionnaire.csv`
- `R1-issue-log.csv`
- `v0.2-usability-r1-freeze.md`

不得在檔名中放姓名、學校或生日。
