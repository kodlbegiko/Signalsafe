# SignalSafe Round 1 Test-Day Checklist

候選 App：`0.2.3-usability-r1-hotfix3`  
Question Bank：`2026-08-01-r1`  
Production：`https://signalsafe-v02-usability-r1.vercel.app`

> 只有在 pre-usability freeze Gate 正式通過後才能執行 UT001–UT004。此清單處理可用性，不等於教育成效驗證。

## 測試前 5 分鐘

- [ ] 直接開啟正式 Production URL，不使用 localhost、mock 或重建頁
- [ ] 頁尾 App version 與本清單一致
- [ ] 頁尾 Question Bank version 與本清單一致
- [ ] Wi-Fi／行動網路可用；另保留離線備援說明
- [ ] 裝置電量充足
- [ ] 記錄裝置類型與 Chrome／Safari 版本，不記錄裝置持有人姓名
- [ ] 關閉通知與其他會暴露個資的畫面
- [ ] 確認前一位受測者資料已清除
- [ ] 清除後確認已產生新的 anonymous ID
- [ ] 確認本場 participant ID 為 UT001–UT004 之一
- [ ] 完成適當 consent；未滿 18 歲者依場域要求完成家長／監護人／校方同意
- [ ] 主持人提醒可隨時退出、不需提供真實可疑訊息或個資

## 每位受測者｜15–20 分鐘

### 任務 1｜首頁與 90 秒快練

- [ ] 不提示按鈕位置，觀察是否自行找到「開始 90 秒快練」
- [ ] 完成 3 題
- [ ] 每題只選最安全行動＋一個最重要訊號
- [ ] 記錄提示次數、誤觸、困惑與完成狀態

### 任務 2｜完整能力測驗／研究模式

- [ ] 能找到課堂／研究模式
- [ ] 確認理解三分類：有明顯風險／資訊不足／目前較可信
- [ ] 依測試腳本完成指定流程；正式 24 題資料只在凍結版本上收集
- [ ] 觀察 pause / resume 是否能理解

### 任務 3｜急救模式

- [ ] 能找到急救入口
- [ ] 能說出現在先停止什麼
- [ ] 能找到獨立官方查證方向
- [ ] 不要求貼真實訊息、截圖、帳密、OTP 或金融資料

### 任務 4｜資料操作

- [ ] 找到匿名 ID
- [ ] 匯出 JSON
- [ ] 匯出 CSV
- [ ] 說明清除資料的後果

### 觀察規則

- [ ] 只記錄可觀察事實，再另欄記推測
- [ ] 每次提示都計數
- [ ] 完成狀態依事前定義標記
- [ ] 原話只保存完成去識別化後仍必要的片段
- [ ] 問題依 P0–P3 分級；不得為了好看而降低等級

## 每位結束後

- [ ] 匯出匿名 JSON，檔名只使用 participant ID／日期／版本
- [ ] 匯出匿名 CSV（如分析需要）
- [ ] 完成 observer form
- [ ] 完成 post-session questionnaire
- [ ] 確認 technical incident 是否需要紀錄
- [ ] 確認沒有姓名、學校、班級、電話、Email、社群帳號、臉部影像或原始聲音進入公開資料
- [ ] 清除 App 本機資料
- [ ] 確認舊 session 消失並產生新的 anonymous ID
- [ ] 回到首頁，為下一位建立 clean state

## 當日停止條件

若發現任何 P0，或 P1 使核心任務無法完成，立即停止後續正式場次並保留證據；修正後必須重新凍結版本。不得把不同核心版本的 Round 1 場次混為同一凍結樣本。
